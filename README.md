# ai-websites

A collection of websites created with the help of AI.

Each project in this repository explores how AI tools and carefully written prompts can be used to design and build a complete website. Projects include the generated site, its source code, and the prompt or instructions used during development.

## Projects

- `landing-page-using-codex` - Fern & Clay, an editorial landing page for an independent plant shop and greenhouse.
- [`restaurant website`](restaurant%20website/README.md) - Italiano, a contemporary Italian restaurant website with home, menu, and about pages.

## Running a project

Each website is self-contained. Open the project directory and follow its README for installation and development commands.

```bash
cd "restaurant-website"
pnpm install
pnpm dev
```

See the [Fern & Clay README](landing-page-using-codex/README.md) for the setup instructions for that project.

More AI-built websites and prompt experiments will be added over time.
