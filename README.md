# ai-websites

A collection of websites created with the help of AI.

Each project in this repository explores how AI tools and carefully written prompts can be used to design and build a complete website. Projects may include the generated site, its source code, and the prompt or instructions used during development.

## Projects

- `landing-page-using-codex` - Fern & Clay, an editorial landing page for an independent plant shop and greenhouse.

More AI-built websites and prompt experiments will be added over time.

inspiration from this workshop https://github.com/katia-openai/master-dev-workshop
